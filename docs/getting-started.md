# Getting started

Canonical walkthrough (Docker Compose and native all-in-one, including Pi/ARM): [getting-started.md](getting-started.md).

Shortest commands from a clone:

```bash
make prove
make up
```

`make up` is an alias for `make up-local` (hyphen required — not `make up local`). Helm is a sketch; Compose is the supported deploy. See [limitations.md](limitations.md).
